HUY:CYBERPUNK — PWA

Cách dùng:
1. Đưa toàn bộ thư mục này lên một website có HTTPS (GitHub Pages, Netlify, Vercel, v.v.).
2. Mở địa chỉ website bằng Safari trên iPhone.
3. Nhấn Chia sẻ -> Thêm vào Màn hình chính.
4. Mở Huy:Cyberpunk từ biểu tượng ngoài màn hình chính.

Lưu ý:
- PWA cần HTTPS để Service Worker hoạt động.
- Bản game đã dùng HTML mobile tối ưu có nút kỹ năng.
- Không phải file IPA và không cần Mac để sử dụng.
